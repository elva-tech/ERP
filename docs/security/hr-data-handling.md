# HR data handling baseline

- Classify employee data by sensitivity and document who may access it.
- Separate ordinary employee profile access from payroll, compensation, bank, identity-document, and disciplinary access.
- Use synthetic data in development, demos, screenshots, and automated tests.
- Minimize personal data in logs, analytics, exports, and support tooling.
- Require explicit authorization for bulk exports and sensitive document downloads.
- Define retention, correction, deletion, and legal-hold behavior with the appropriate business/legal owners.
- Audit sensitive administrative changes and access where appropriate.
- Ensure notifications do not expose salary, bank details, government identifiers, or confidential HR information.
